KACHER DOKAN - SPRING BOOT FINAL

1. Install Java 21 and Apache Maven.
2. Double-click RUN_SPRING_WINDOWS.bat.
3. Open http://localhost:3000 in your browser.
4. For mobile, keep phone and laptop on the same Wi-Fi and set kaser-dokan-mobile/.env to:
   EXPO_PUBLIC_API_URL=http://YOUR_LAPTOP_IP:3000
5. In a second terminal:
   cd kaser-dokan-mobile
   npm install
   npx expo start -c

Backend: Spring Boot + Spring Data MongoDB
Database: MongoDB Atlas (same kaser_dokan data)
