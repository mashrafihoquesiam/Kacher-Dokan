# Phase 1 & 2: Testing Guide

## Complete Testing Workflow

This guide provides step-by-step instructions to test all Phase 1 (User Management) and Phase 2 (Authentication) features.

---

## Prerequisites

1. **Start MongoDB**
   - Windows: Run MongoDB service or execute mongod.exe
   - Mac: `brew services start mongodb-community`
   - Linux: `sudo systemctl start mongod`

2. **Build and Run Application**
   ```bash
   cd "c:\Users\user\Desktop\kaser dokan\kaser-dokan-backend"
   mvn clean install
   mvn spring-boot:run
   ```

3. **Expected Output:**
   ```
   Started KaserDokanApplication in X.XXX seconds
   Server running on http://localhost:8080/api
   ```

4. **Verify Server Health**
   ```bash
   curl http://localhost:8080/api/users/health
   ```
   Expected: `User service is running`

## Test Scenario 1: User Registration (Phase 1)

### Test 1.1: Register Customer User

**Endpoint:** `POST http://localhost:8080/api/users/register`

**Request:**
```json
{
  "name": "Ahmed Rahman",
  "phone": "01912345678",
  "email": "ahmed@example.com",
  "password": "password123",
  "confirmPassword": "password123",
  "role": "USER"
}
```

**Expected Response:** 201 Created
```json
{
  "success": true,
  "message": "User registered successfully",
  "data": {
    "id": "64f3a1b2c5d6e7f8g9h0i1j2",
    "name": "Ahmed Rahman",
    "phone": "01912345678",
    "email": "ahmed@example.com",
    "role": "USER",
    "latitude": null,
    "longitude": null,
    "active": true,
    "createdAt": "2026-08-31T10:30:00",
    "updatedAt": "2026-08-31T10:30:00"
  }
}
```

**✅ Test Passed If:**
- Response code is 201
- User object returned with all fields
- ID is generated by MongoDB
- createdAt timestamp is set

**Save the user ID** for later tests: `64f3a1b2c5d6e7f8g9h0i1j2`

## Common Issues & Solutions

### Issue: MongoDB Connection Failed
```
Solution:
1. Verify MongoDB is running
2. Check mongodb://localhost:27017/kaser_dokan in application.properties
3. Restart MongoDB service
```

### Issue: Port 8080 Already in Use
```
Solution:
Change port in application.properties:
server.port=8081
```

### Issue: Token Expired
```
Solution:
JWT tokens expire after 24 hours. 
Call login endpoint again to get a new token.
In Phase 3+, implement refresh token mechanism.
```

### Issue: "Unauthorized" on Protected Endpoints
```
Solution:
1. Ensure Authorization header is present
2. Format: Authorization: Bearer <token>
3. Verify token from login response
4. Check token hasn't expired
```
